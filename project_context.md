## 1. What this is

A single-page personal portfolio website for **Md Jonayed**, a **business coach, trainer, consultant, strategy planner, speaker, investor and tech entrepreneur**.

- **Goal:** turn qualified visitors (founders, leadership teams, event organisers, co-investors) into an **email enquiry**. Email (`mailto:`) is currently the only conversion.
- **Tone:** modern, innovative, *slightly* techy (not too techy), business-like. Calm, trusted advisor rather than a hype funnel.
- **Visual reference:** a dark, photo-led personal-brand coaching site (full-bleed portrait hero, role columns along the bottom of the hero, light content sections, testimonials).
- **Status:** design and structure are built. **Most content is placeholder** (see §8). Not deployed yet.

## 2. Tech stack

| Layer | Choice | Notes |
|---|---|---|
| Framework | **Next.js 16.4** (App Router, Turbopack) | ⚠ Newer than most training data. Read `node_modules/next/dist/docs/` before using unfamiliar APIs (see `AGENTS.md`). |
| UI | **React 19.3**, **TypeScript 5** (strict) | Path alias `@/*` → `src/*` |
| Styling | **Tailwind CSS v4** | CSS-first config: tokens live in `@theme` in `src/app/globals.css`. There is **no** `tailwind.config.js`. |
| Animation | **GSAP 3.15** + `@gsap/react` (`useGSAP`) | Plugins: **ScrollTrigger**, **SplitText** (free since 3.13), registered once in `src/lib/gsap.ts`. |
| Smooth scroll | **Lenis 1.3** | Driven by GSAP's ticker so ScrollTrigger stays in sync. |
| Fonts | **Geist** + **Geist Mono** via `next/font/google` | CSS vars `--font-geist`, `--font-geist-mono`. |
| Images | `next/image` | SVGs need `unoptimized`. |
| Lint | ESLint 9 + `eslint-config-next` | `.claude/**` and `.impeccable/**` are ignored. |

`next.config.ts` enables `cacheComponents: true` and `partialPrefetching: true`.
**Consequence:** values that change per request, such as `new Date()`, break static prerendering, even in client components. That's why the footer year is a constant (`site.year`), not `new Date().getFullYear()`.

## 3. Commands

```bash
npm install        # install deps
npm run dev        # dev server → http://localhost:3000
npm run build      # production build (static prerender of "/")
npm run start      # serve the production build
npm run lint       # ESLint
npx tsc --noEmit   # type-check
```

⚠ **Don't run `npm run build` while `npm run dev` is running.** They share `.next/`, and the dev server then serves stale CSS (new Tailwind tokens "disappear"). Stop dev, build, then restart dev.

Claude Code preview config: `.claude/launch.json` (server name `dev`, port 3000).

## 6. Design system (summary; full spec in `DESIGN.md`)

**"Graphite & green"**: dark graphite bands, cool paper ground, one business green for actions, mint for small signals on dark.

| Token (Tailwind class suffix) | Hex | Use |
|---|---|---|
| `ink` / `ink-2` / `ink-3` | #0d1117 / #151b23 / #232b36 | dark backgrounds / elevated / borders |
| `on-ink` / `on-ink-soft` | #eef1ee / #9aa4ae | text on dark |
| `paper` / `card` / `line` | #f3f4f0 / #ffffff / #e1e4dd | light backgrounds / cards / borders |
| `text` / `text-soft` / `text-mute` | #11161c / #454e57 / #5f6870 | text on light |
| `primary` / `primary-press` | #1a6b50 / #145540 | buttons & links on light (white text 7.3:1) |
| `mint` / `mint-soft` | #9be1c3 / #e2f3ea | actions & signals on dark / tints on light |

Custom utilities in `globals.css`:
- `display`: heading style (600 weight, -0.035em tracking, tight leading, balanced wrap). Max size 6rem.
- `btn`: 44px pill button base. Add colour classes per context.
- `bg-grid` / `bg-grid-light`: faint measured grid backgrounds (the "techy" texture).
- `.on-ink`: put on dark sections so focus rings turn mint.

**Rules:**
- Use tokens, never raw hex, in components.
- Actions: `bg-primary text-white` on light, `bg-mint text-ink` on dark.
- Geist Mono **only** for numbers, indexes and years. Not for decoration.
- Icons come from `Icons.tsx` (consistent 1.5px stroke). No emoji or Unicode glyphs as icons.
- No neon glow, glassmorphism, or terminal pastiche. The tech feel comes from grids, rules, progress lines and mono numerals.
- Body text measure ≤ ~65ch. Maintain WCAG AA contrast.

**Logo:** MJ monogram. One continuous stroke draws the M and its right leg hooks into a J; a small mint square is the "growth node". Component `Logo.tsx` (`<Logo />` lockup, `<LogoMark variant="tile|glyph" />`). Files in `public/brand/` (SVG + PNG 512–4096px). Favicon: `src/app/icon.svg`.

## 7. Animation and motion conventions

- Always import from `@/lib/gsap` (`gsap`, `ScrollTrigger`, `SplitText`, `useGSAP`), never directly from `gsap`, so plugins are registered.
- Use `useGSAP(() => {...}, { scope: ref })` so selectors are scoped and everything auto-reverts.
- Wrap motion in `gsap.matchMedia()` with `(prefers-reduced-motion: no-preference)`. Content must be fully visible and usable with motion off.
- **SplitText + React gotcha:** SplitText rewrites an element's children. If React later changes that element's text, the update is lost. Fix: give the split element a `key` that changes with the content (see `QuoteBand.tsx`, `<p key={i}>`), or only split static text.
- Signature motions: hero name reveal, Philosophy word ink-in, Approach timeline draw, quote reveal. Don't add a generic fade-in to every section; keep motion purposeful.
- Lenis: `getLenis()?.stop()` / `.start()` from `@/lib/lenis` (used by the mobile menu).

## 9. How-to recipes

**Change text or data:** edit `src/content/site.ts`. No component changes needed.

**Replace the hero photo:** save it as `public/portrait.jpg` (wide, ~16:9, dark, subject on the right third, ≥2400px wide, <400KB), or change `site.portrait`. Tune the crop in `Hero.tsx` via `object-[x%_y%]` classes (mobile and `lg:` variants).

**Add a section:**
1. Create `src/components/MySection.tsx`. Add `"use client"` only if it uses hooks or GSAP.
2. Add its content to `site.ts`.
3. Insert it in `src/app/page.tsx`, respecting the dark/light alternation.
4. If it needs a nav link, add `{ href: "#id", label }` to the `links` array in **both** `Nav.tsx` and `Footer.tsx`.
5. Container pattern: `mx-auto max-w-[1240px] px-4 sm:px-8 py-24 lg:py-32`.

**Add a colour token:** add `--color-name: #hex;` inside `@theme` in `globals.css`, then use `bg-name` / `text-name`. Restart dev if it doesn't appear (see §3).

**Add an icon:** add a component to `Icons.tsx` using the shared `base` stroke props.
